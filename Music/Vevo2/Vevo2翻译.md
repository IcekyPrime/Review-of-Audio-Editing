# Vevo2：一个用于语音和歌声生成的统一可控框架

Xueyao Zhang, Junan Zhang, Yuancheng Wang, Chaoren Wang, Yuanzhe Chen, Dongya Jia, Zhuo Chen, Zhizheng Wu

**摘要**——可控的人类声音生成，尤其是对于像歌声这样富有表现力的领域，仍然是一个重大挑战。本文介绍了 Vevo2，一个用于可控语音和歌声生成的统一框架。为解决标注歌声数据稀缺等问题并实现灵活可控性，Vevo2 引入了两个音频 tokenizer：（1）一个统一的、无需乐谱的韵律 tokenizer，能够从语音、歌声甚至器乐声音中捕获韵律和旋律；（2）一个统一的内容-风格 tokenizer，为语音和歌声编码语言内容、韵律和风格，同时实现音色解耦。Vevo2 由一个自回归内容-风格建模阶段（旨在实现对文本、韵律和风格的控制）以及一个流匹配声学建模阶段（允许音色控制）组成。特别地，在 AR 模型的语音-歌声联合训练期间，我们提出了显式和隐式两种韵律学习策略，以桥接语音和歌声。此外，为了进一步增强 Vevo2 遵循文本和韵律的能力，我们设计了一个多目标后训练任务，整合了可懂度和韵律相似度对齐。实验结果表明，Vevo2 中的统一建模为语音和歌声生成带来了互惠互利。此外，Vevo2 在语音和歌声的广泛合成、转换和编辑任务中的有效性，进一步证明了其强大的泛化能力和多功能性。音频样本可在 https://versasinger.github.io/ 获取。

**索引词**——语音生成，歌声合成，文语转换，语音转换，编辑，音乐生成，后训练

## I. 引言

可控的人类声音生成是音频生成领域的一个重要研究课题 [1], [2]。近年来，语音生成取得了显著进展，特别是在零样本文语转换（TTS）方面 [3]-[6]，这很大程度上得益于大规模训练语料库的可用性。然而，对于更具挑战性的领域，如歌声——它可以被视为一种具有严格约束韵律（如旋律）的高度表达性语音形式 [7]——同时实现高生成质量和可控性仍然具有挑战性 [8], [9]。

本文关注统一可控的语音和歌声生成。我们的动机基于这样一个假设：通过统一建模，语音和歌声的学习可以互惠互利。具体来说，（1）语音 \(\rightarrow\) 歌声：丰富的语音数据可以补充通常较小的歌声数据集 [10], [11]，有可能提高生成歌声的整体质量 [9]。（2）歌声 \(\rightarrow\) 语音：歌声固有的表达性，当被纳入统一学习框架时，可以增强表达性语音生成 [12]。此外，由于歌声本质上包含结构化的旋律模式，学习对其建模有助于系统增强遵循旋律的能力，从而提高整体的韵律遵循能力。这种能力对于诸如韵律保持的语音编辑等任务尤其有益（第 V-B 节）。

最近有几项研究尝试统一语音和歌声生成。例如，UniSyn [13] 通过一个任务标识符在生成模式之间切换，整合了 TTS 和歌声合成（SVS），而 UniAudio [14] 通过任务条件序列建模将此概念扩展到更广泛的音频生成任务。尽管这些方法代表了有价值的进展，但它们仍面临两个基本挑战。第一，现有的歌声生成语料库严重依赖专家标注 [15]-[18]，例如歌词与音符之间精确对齐的详细乐谱 [11], [19], [20]。这些数据集稀缺，且其独特的数据组织方式本质上与大规模语音语料库不一致，从而限制了可扩展性和统一训练。第二，在这样的统一系统中实现多方面的可控性仍然并非易事——例如在单一框架内独立操纵文本（或歌词）、韵律（或旋律）、风格（如口音、情感或演唱技巧 [11], [21]）和音色（即说话人身份）。

为应对这些挑战，本文介绍了 Vevo2，一个旨在统一语音和歌声的多功能可控声音生成框架。Vevo2 采用两阶段架构，类似于经典的零样本语音生成系统 [4], [6], [22]（图1）：（1）自回归（AR）内容-风格建模阶段：给定目标文本和韵律源作为输入，我们利用 AR transformer 生成内容-风格 token，由风格参考进行提示。（2）流匹配（FM）声学建模阶段：给定内容-风格 token 作为输入，我们采用 FM transformer 产生声学表示（在我们的研究中具体为梅尔频谱图），由音色参考进行提示。为实现所需的统一性和可控性，Vevo2 引入了以下三个关键方法设计：

1. **统一的语音和歌声 tokenizer**。我们提出了两个不同的音频 tokenizer：一个统一的韵律 tokenizer 和一个统一的内容-风格 tokenizer。（1）韵律 tokenizer：一个单码本 VQ-VAE tokenizer [23], [24]，运行于 6.25 Hz（56.25 bps），训练用于重建原始音频的 chromagram [25]（图2a）。该 tokenizer 统一了歌声中旋律和语音中韵律的建模，并可直接从原始音频的 chromagram 提取 token，无需专家标注的乐谱，从而大大提高了可扩展性。此外，由于 chromagram 在各种音频数据上具有强大的泛化能力 [25], [26]，该 tokenizer 甚至可以捕获器乐等非人类声音的旋律（第 V-F 节），从而实现独特的音乐生成应用，如哼唱到歌唱和器乐到歌唱。（2）内容-风格 tokenizer：它采用与韵律 tokenizer 类似的架构，但运行于 12.5 Hz（175 bps），训练用于重建 chromagram 特征和 Whisper 隐藏特征 [27]（图2b）。它有效捕获语音和歌声中的语言内容、旋律和风格，同时实现稳健的音色解耦（表 III）。

2. **语音-歌声联合训练**。为解决语音和歌声的联合训练，我们在内容-风格建模阶段设计了两种不同的训练策略：（1）显式韵律学习（EPL），其中韵律 token 作为显式输入提供，允许模型从文本和韵律 token 两者预测内容-风格 token；（2）隐式韵律学习（IPL），其中韵律 token 不作为输入，内容-风格 token 仅从文本 token 预测。通过随机将 EPL 和 IPL 应用于所有语音数据，模型以更统一的方式学习韵律，有效桥接了语音和歌声特征之间的差距。

3. **多目标对齐**。为进一步提高预训练模型的文本和韵律遵循能力，我们引入了一个多目标后训练任务。我们提出了一种复合奖励，结合了可懂度和韵律相似度，并采用组相对策略优化（GRPO）算法 [28] 进行训练。实验结果表明，这种后训练显著增强了模型对文本和旋律的可控性，并提高了其对预训练分布之外数据（如器乐声音）的泛化能力。

本文的贡献总结如下：

- 我们提出了两个音频 tokenizer：（1）一个统一的、无需乐谱的韵律 tokenizer，能够从语音、歌声甚至器乐声音中编码韵律和旋律；（2）一个统一的、音色解耦的内容-风格 tokenizer，为语音和歌声建模语言内容、韵律和风格。
- 我们介绍了 Vevo2，一个用于语音和歌声生成的统一可控框架。基于所提出的语音-歌声联合训练，Vevo2 可以通过在推理期间灵活组合文本、韵律源以及风格和音色参考，应用于多方面的声音合成、转换和编辑任务。
- 我们提出了一个用于可控声音生成的多目标后训练任务。通过使用基于 GRPO 的算法优化可懂度和韵律相似度奖励，Vevo2 在各种任务中实现了更高的稳定性和改进的整体性能。我们将在 Amphion [29], [30] 发布本研究的代码和模型检查点。

## II. 相关工作

**可控声音生成**。可控语音和歌声生成一直是一个重要的研究焦点。（1）在语音领域，现有工作探索了对多个属性的控制：语言内容，这是 TTS [1], [2] 和语音编辑任务 [31]-[34] 的基础；音色，这是 VC 任务的核心 [3], [22], [35]-[38]；以及风格，涵盖口音 [22], [39], [40]、情感 [22], [41], [42]、耳语 [43] 和更广泛的自然语言描述 [44]-[46]。（2）对于歌声，除了控制歌词、音色和风格——如在 SVS [16], [17], [47]-[49]、SVC [50]-[53] 和歌唱歌词编辑任务 [54]-[56] 中所探索的——旋律控制尤为重要，因为歌声固有的音乐性 [8], [9], [26]。（3）从统一建模的角度来看，先前的研究尝试整合各种语音生成任务，如 TTS 和 VC [6], [22], [57]，或不同的歌声生成任务，如 SVS 和 SVC [55], [58]。然而，能够统一语音和歌声两个领域的模型仍然稀缺 [13], [14]。此外，语音和歌声联合预训练的潜在益处，以及统一系统中对多种声音属性的多方面控制机制，在很大程度上仍未被探索。

**语音 Tokenizer**。最近的研究强调了解耦语音表示学习，旨在分别建模因子化的语音属性以降低学习复杂度 [3], [59] 并实现更精确的可控性 [3], [22], [60]。常见的语音 tokenizer 包括语言内容 tokenizer [22], [61], [62]、内容-风格 tokenizer [4]-[6], [22], [63] 和韵律 tokenizer [3], [59]。然而，在追求用于语音和歌声生成的统一可控模型时，现有的语音 tokenizer 表现出若干局限性：由于这些 tokenizer 主要关注语音领域，它们在处理歌声数据方面的有效性仍未被探索。设计一个能够处理两种模态的统一韵律 tokenizer，以及增强内容-风格 tokenizer [53] 的旋律编码能力，仍然是未来探索的重要问题。

**音频生成的后训练**。通过后训练进行对齐已在文本 [64], [65]、视觉 [66], [67]、语音 [4], [68], [69]、音乐 [70] 和音效 [71], [72] 的生成中展示了其有效性。在语音生成中，现有工作采用偏好对齐来增强语音的多个方面，包括可懂度 [4], [69], [73]、说话人相似度 [4], [69]、情感可控性 [4], [74] 和整体质量 [68], [75], [76]。对于开发统一的语音和歌声生成模型，鉴于注入预训练模型的能力范围扩大，通过后训练引发特定能力的重要性变得尤为关键。然而，为统一语音和歌声生成设计适当的对齐目标仍然是一个开放的研究问题。

## III. 方法

Vevo2 的整体架构是一个两阶段、多用途的声音生成框架，统一了语音和歌声（图1）。在推理期间，通过灵活组合不同的输入条件——如文本、韵律源、风格参考和音色参考——Vevo2 支持广泛的声音相关合成、转换和编辑任务（第 III-D 节）。具体来说，Vevo2 首先通过 AR transformer 将语言、风格和韵律线索编码为离散的内容-风格 token，然后通过 FM transformer 重建梅尔频谱图。这些频谱图随后使用基于 Vocos 的声码器 [77] 转换为波形。为实现统一的语音-歌声生成和多方面可控性，Vevo2 建立在几个关键方法设计之上，详见以下各节。

### A. 统一的语音和歌声 Tokenizer

**韵律 Tokenizer**。为了用统一的方法建模语音的韵律和歌声的旋律，我们选择 chromagram 特征 [25] 并基于它设计了一个 VQ-VAE tokenizer [23], [24]。一些先前的语音生成研究尝试使用基频（F0）[3], [60] 或梅尔频谱图的低频带 [59] 来构建韵律 tokenizer。我们采用 chromagram 的原因如下：

1）**无八度，因此便于统一**：语音和歌声之间的 F0 存在显著分布差距，例如歌声的 F0 范围要宽得多 [78]。Chromagram 去除了歌声和语音之间的八度信息，使得更容易捕获两个领域共同的韵律模式。
2）**无需乐谱，因此便于扩展**：Chromagram 有效表示高层音乐和歌声属性，如旋律和和声 [25]，并且可以从音频自动提取而无需手动转录或乐谱，使其适合大规模数据处理。
3）**对多样化音频领域稳健**：作为频谱能量的统计分布，chromagram 对噪声和音高检测误差不太敏感 [79]，从而产生更稳定的性能。此外，chromagram 为人类声音和非人类声音（如器乐）都提供了强表示 [25], [26]。这些特性增强了下游音乐生成任务中旋律控制的灵活性，例如实现器乐到歌唱应用（第 V-F 节）。

虽然连续 chromagram 可以直接用作条件信号，但我们采用 VQ 量化来获得紧凑的离散韵律 token，这更适合我们的序列建模流程并且对声学变化更稳健（见附录的经验分析）。韵律 tokenizer 由五个主要组件组成（图2a）：下采样层（基于 CNN）、编码器、向量量化（VQ）、解码器和上采样层（基于 CNN）。形式上，给定码本 \(\pmb {E} = [e_{1},e_{2},\ldots ,e_{K}]\)，词汇量为 \(K\)，以 chromagram 特征 \(\pmb{x}\) 为输入，经过这五个模块后获得重建输出 \(\hat{x}\)：

\[\begin{array}{rl} & z_{e}(x) = \mathrm{Encoder}(\mathrm{Downsample}(x)),\\ & z_{q}(x) = e_{k},\mathrm{where}k = \arg \min_{j}\| z_{e}(x) - e_{j}\|_{2},\\ & \hat{x} = \mathrm{Upsample}(\mathrm{Decoder}(z_{q}(x))), \end{array} \quad (1)\]

其中 \(z_{q}(x)\) 是 \(z_{e}(x)\) 经过 VQ 后的量化表示（即 token）。损失函数由重建损失（权重为 \(\lambda\)）和量化损失（权重为 \(\beta\)）组成：

\[\mathcal{L} = \lambda \| \pmb {x} - \hat{\pmb{x}}\|_{2}^{2} + \beta \| \pmb {z}_{e}(\pmb {x}) - \pmb {z}_{q}(\pmb {x})\|_{2}^{2}. \quad (2)\]

我们遵循 [5], [24], [80] 并采用因子化（即低维码查找空间）和 L2 归一化策略进行 VQ 学习。我们从原始音频提取 50 Hz chromagram 特征并应用 8 倍下采样，得到运行于 6.25 Hz（56.25 bps）的韵律 tokenizer。

**内容-风格 Tokenizer**。我们遵循最近可控语音生成工作的主要思想 [6], [22]，旨在开发一个内容-风格 tokenizer，能够编码语言内容、韵律和风格，同时实现音色解耦。特别地，为统一语音和歌声，除了像典型语音生成任务 [4]-[6], [22], [81] 那样编码语言内容和风格外，我们还要求 tokenizer 捕获歌声中的旋律和细粒度风格信息（例如 F0 和能量细节）。受此启发，在设计我们的 VQ-VAE tokenizer 时，我们不仅使用自动语音识别（ASR）模型的隐藏特征——具体来说，来自 Whisper [27] 的特征——作为重建目标，还纳入 chromagram 特征作为额外的重建目标。这补偿了 Whisper 特征在建模歌声旋律方面的局限性 [53]。此外，为了促进下游内容-风格建模阶段，我们设计内容-风格 tokenizer 运行于相对较低的帧率（在我们的研究中具体为 12.5 Hz）。这减少了 AR 模型的序列长度，从而减轻其学习负担。

内容-风格 tokenizer 的架构与所提出的韵律 tokenizer 类似，如图2b所示。唯一区别在于输入和重建目标同时包含 chromagram 特征和 Whisper 特征。我们提取 50 Hz chromagram 特征和 50 Hz Whisper 特征（即预训练 Whisper 模型 [27] 的编码器输出）并应用 4 倍下采样，得到运行于 12.5 Hz（175 bps）的内容-风格 tokenizer。

### B. 语音-歌声联合训练

为进行语音和歌声的联合训练，一个关键问题在于如何在单一框架内统一语音和歌声的生成过程。对于声学建模阶段，一旦获得所提出的统一内容-风格 tokenizer，这部分就变得相对简单，因为语音和歌声都可以被表述为统一的内容-风格 token 并在音色参考的指导下解码为梅尔频谱图。然而，我们观察到语音-歌声联合训练的主要挑战出现在内容-风格建模阶段，其中语音和歌声的生成特征存在显著差异。例如，像 TTS 这样的语音生成通常仅以文本（和参考）作为输入，不使用对韵律的显式控制 [1]，而歌声生成通常要求对旋律的直接控制 [15]-[18]。

受此观察启发，我们关注统一韵律学习，并在内容-风格建模阶段提出两种不同的训练策略来桥接语音和歌声生成（图3）：（1）隐式韵律学习（IPL）：AR 模型仅从文本输入生成内容-风格 token，通过上下文学习隐式推断韵律信息。该策略通常在零样本 TTS 系统 [4]-[6], [22], [63] 中采用。（2）显式韵律学习（EPL）：除文本输入外，还显式提供韵律 token，允许 AR 模型以文本和韵律信息两者为条件预测内容-风格 token。值得注意的是，在联合训练期间，我们不将 IPL 限制于语音数据、EPL 限制于歌声数据。相反，我们平等对待所有样本：对于每个训练样本，我们以相等概率在 IPL 和 EPL 之间随机选择。我们假设这种设计更好地统一了语音和歌声的训练模式。

给定语音或歌声样本 \(u\)，我们将韵律和内容-风格 token 分别记为 \(Q_{p}(u)\) 和 \(Q_{cs}(u)\)。IPL 和 EPL 的 transformer 输入序列如公式 (3) 和 (4) 所示，其中 \(I_{ipl}\) 和 \(I_{epl}\) 表示 IPL 和 EPL 的文本指令前缀，\(T\) 表示 \(u\) 的文本，\(\langle \cdot \cdot \cdot \rangle\) 表示特殊 token：

\[\begin{array}{rl} & {\mathbf{IPL}:[I_{ipl},T,\langle \mathrm{start - of - cs}\rangle ],Q_{cs}(u),\langle \mathrm{end - of - cs}\rangle ],}\\ & {\mathbf{EPL}:[I_{epl},T,\langle \mathrm{start - of - p}\rangle ],Q_{p}(u),\langle \mathrm{end - of - p}\rangle ],}\\ & {\qquad \langle \mathrm{start - of - cs}\rangle ],Q_{cs}(u),\langle \mathrm{end - of - cs}\rangle ].} \end{array} \quad (4)\]

具体来说，IPL \((I_{ipl})\) 和 EPL \((I_{epl})\) 的文本指令前缀分别定义为：“User will provide you with a text. Please vocalize it with natural expression.” 和 “User will provide you with a text. Please first generate a good prosodic instruction, then vocalize the text based on it.”。对于 IPL 和 EPL，我们仅在最终片段 \([\langle \mathrm{start - of - cs}\rangle ],Q_{cs}(u),\langle \mathrm{end - of - cs}\rangle ]\) 上执行下一 token 预测。

在声学建模阶段，我们采用 FM transformer 将内容-风格 token 转换为梅尔频谱图，以音色参考为条件。此过程遵循语音生成研究中使用的一般范式 [6], [8], [22], [82]，区别在于我们的方法利用所提出的统一内容-风格 tokenizer，并在语音和歌声数据上联合训练。获得梅尔频谱图后，我们使用基于 Vocos 的声码器 [77]（也在语音和歌声上训练）重建最终波形。

### C. 多目标对齐

预训练后，我们观察到 AR 模型在不同任务中表现出良好的多功能性（第 V 节）。然而，其稳定性仍然不够理想，特别是在其文本和韵律遵循的基本能力方面，这些能力可以进一步引发和增强。此外，在下游应用中，模型可能遇到预训练分布之外的数据，如器乐声音。例如，在 SVS 的背景下，模型需要接受从 MIDI 渲染的声音中提取的韵律 token 以进行旋律控制（图1）。

受上述启发，本研究进一步采用后训练来增强模型对文本和韵律的可控性，以及提高其对多样化音频数据的鲁棒性。我们提出了一个多目标后训练任务，联合对齐可懂度和韵律相似度（图4）。我们相信这种联合对齐有助于防止模型过度优化单一目标（如第 V-F 节所证明）。

**可懂度奖励**。为对齐可懂度，我们采用最近的零样本 TTS 可懂度偏好语料库 INTP [73]，其中包含通过多个模型之间的比较以及人工设计的可懂度扰动构建的多样化可懂度偏好对，以训练可懂度奖励模型。具体来说，我们采用常用的 Bradley-Terry（BT）方法 [64], [65], [83] 进行奖励模型训练。给定可懂度偏好数据集 \(\mathcal{D} = \{(t,a^w,a^t)\}\)，其中 \(a^w\) 和 \(a^t\) 分别表示相对于目标文本 \(t\) 的正和负音频输出，我们参数化一个可懂度奖励模型 \(r_{\phi}(t,a)\)，将问题视为二元分类，并优化负对数似然损失：

\[\mathcal{L}_R(r_\phi ,\mathcal{D}) = -\mathbb{E}_{(t,a^w,a^t)\sim \mathcal{D}}\left[\log \sigma \left(r_\phi (t,a^w) - r_\phi (t,a^t)\right)\right],\]

其中 \(r_{\phi}(t,a)\) 从预训练模型初始化。我们遵循预训练并使用 EPL 和 IPL 训练此奖励模型。在推理期间，我们可以输入 \([T,Q_{cs}]\) 或 \([T,Q_p,Q_{cs}]\) 序列以获得可懂度奖励。

**韵律相似度奖励**。为实现韵律对齐，我们建立以下协议来评估策略模型的韵律遵循能力：（1）假设我们有一个带有 MIDI 标注的歌声数据集。给定一个歌声样本 \(u\)，我们使用其 MIDI 渲染的器乐提取韵律 token 作为控制条件，记为 \(Q_{p}\)；（2）让策略模型以 \(Q_p\) 和 \(T\)（\(T\) 可以是任意文本）为条件执行补全，并将生成的内容-风格 token 记为 \(\hat{Q}_{cs}\)；（3）使用内容-风格 tokenizer 的解码器（第 III-A 节），我们从 \(\hat{Q}_{cs}\) 重建 chromagram 特征 \(\hat{\alpha}\)，并计算 \(\hat{\alpha}\) 与歌声 \(u\) 的真实 chromagram 特征 \(\alpha\) 之间的余弦相似度\(^3\)。

**多目标优化**。我们应用 GRPO 算法 [28] 优化所提出的多目标对齐任务。假设每个提示的补全数为 \(K\)，在获得所有 \(K\) 个补全的可懂度奖励 \((r_{int})\) 和韵律相似度奖励 \((r_{pro})\) 后，我们分别对两个奖励应用组归一化。这些归一化奖励之和作为最终结果监督：

\[A^{(i)} = \frac{r_{int}^{(i)} - \mathrm{mean}(r_{int})}{\mathrm{std}(r_{int})} +\frac{r_{pro}^{(i)} - \mathrm{mean}(r_{pro})}{\mathrm{std}(r_{pro})}, \quad (6)\]

其中 \(r_{int}^{(i)}\) 和 \(r_{pro}^{(i)}\) 分别表示第 \(i\) 个补全的可懂度奖励和韵律相似度奖励，\(A^{(i)}\) 表示优势。

### D. 推理时可控性

**文本、韵律、风格和音色控制**。在获得预训练（或后训练）模型后，我们可以按照图1所示的流程进行推理，通过利用文本、韵律源、风格参考和音色参考的不同组合，实现语音和歌声的多方面合成、转换和编辑任务。

在内容-风格建模阶段，例如，当不使用韵律源时，推理范式与经典零样本 TTS [4], [6], [22], [84] 相同。如图1中的 TTS 任务所示，该过程可表示为 [t, t, cs] \(\rightarrow\) [cs]，其中 cs 中的风格信号由 cs 提示并通过预训练模型的上下文学习能力生成。特别地，当同时使用韵律源和风格参考作为输入时，推理范式采取 [t, t, p, p, cs] \(\rightarrow\) [cs] 的形式。在这种情况下，对于 cs，我们期望 p 提供粗粒度的韵律轮廓信号，而 cs 贡献细粒度的风格细节（例如歌声的颤音模式）。我们将通过风格转换歌声转换的实验进一步讨论这一点（第 V-C 节）。

在声学建模阶段，我们可以通过提供音色参考来引入音色控制。具体来说，我们将 AR 模型生成的内容-风格 token 与从音色参考中提取的 token 拼接，并联合以参考的梅尔频谱图为条件来调节 FM 模型，即图1中的 [cs, mel, cs] \(\rightarrow\) [mel]。这种双重条件引导模型合成目标话语，具有来自 AR 输出的语言、韵律和风格内容，同时采用参考中嵌入的音色特征。值得注意的是，我们也可以仅使用 FM 模型进行风格保持的 VC 或 SVC 任务。具体来说，AR 生成的内容-风格 token 可以替换为直接从源音频提取的 token，即图1中的 [cs, mel, cs] \(\rightarrow\) [mel]。

**时长控制**。一些基于非 AR 的语音生成模型通常具有控制生成语音总时长的能力 [5], [34]，而基于 AR 的模型通常被认为不太能控制输出时长 [4], [6], [22], [63], [85]。然而，有趣的是，我们发现 Vevo2 可以通过使用韵律 token 作为输入来有效控制生成结果的时长。这种能力源于我们 tokenizer 的固定帧率（6.25 Hz 和 12.5 Hz），在训练期间保持内容-风格和韵律 token 序列之间一致的 2:1 比例。因此，在推理期间，我们可以通过将简单线性缩放变换应用于韵律源的 chromagram 特征，从而修改韵律 token 的长度，来控制生成输出的时长。这种控制机制在第 V-D 节中详述。

**音高区域控制**。对于语音转换（VC）或歌声转换（SVC）任务，由于源说话人和参考说话人之间可能存在显著的音色类型差异 [7], [21]，我们通常需要在推理期间调整源波形的音高区域（即应用音高偏移）以实现更高的说话人相似度 [50], [52], [53]。在 Vevo2 中，我们发现音高区域控制也可以实现：通过在韵律 token 提取之前对源波形进行音高偏移，我们可以有效控制生成语音或歌声的音高区域。我们的实验证明，这种方法在仅使用 FM 阶段以及结合 AR 和 FM 阶段时都有效。这种控制机制在第 V-E 节中详述。

## IV. 实验设置

### A. 数据和指标

**训练数据**。对于预训练，我们使用 Emilia [10] 作为语音数据（101K 小时），并遵循 SingNet 的流程 [86] 准备 7K 小时的歌声数据（从互联网上的野外歌曲中源分离）。对于后训练，我们利用 INTP [73]（包含 250K 偏好语音对）训练可懂度奖励模型。对于所提出的多目标对齐任务，我们采用三种类型的韵律提示：（1）语音数据：从 INTP 随机选择的 20K 正样本，（2）歌声数据：来自 M4Singer [19] 的 20K 样本，以及（3）器乐声音：从 M4Singer 中的 MIDI 渲染，涵盖五个类别的 16 种乐器：钢琴、弦乐、木管、铜管和民间乐器。

**评估数据**。我们考虑各种设置来构建评估集：（1）对于常规语音，我们利用 SeedTTS 测试集 [4]，这在 TTS 领域被广泛采用 [5], [34], [69]。（2）对于表达性语音，我们采用 Genshin-Voice [87]，它包含来自游戏《原神》的专业配音录音。（3）对于歌声，我们使用 GTSinger [11] 和 SingStyle111 [20]，它们涵盖了广泛的演唱技巧、风格和音色类型。（4）此外，对于两个独特任务：哼唱到歌唱和器乐到歌唱，我们利用哼唱 [88] 和器乐声音，包括长笛 [89] 和小提琴 [90] 进行评估。所有评估均使用英语和中文的目标文本进行。

**评估指标**。对于客观指标，我们评估可懂度（WER，\(\downarrow\)）、说话人相似度（SIM，\(\uparrow\)）、F0 相关性（FPC，\(\uparrow\)）[22], [50], [53]。对于 WER，我们采用 Whisper-large-v3 [27] 处理英文文本，Paraformer-zh [91], [92] 处理中文文本。对于 SIM，我们计算生成样本和参考语音的 WavLM TDNN [93] 说话人嵌入之间的余弦相似度。对于主观指标，我们采用比较平均意见分数（CMOS，评分范围 -2 到 2，\(\uparrow\)）来评估自然度（N-CMOS）以及说话人、韵律、旋律和风格的相似度（SS-CMOS、PS-CMOS、MS-CMOS 和 Style-CMOS）。此外，我们使用 Melody-MOS 评估旋律遵循能力（评分范围 1 到 3，分别对应“无法遵循”、“大致遵循旋律轮廓”和“完全遵循所有旋律细节”）。受试者的详细背景和所有主观指标的定义在补充材料中提供。

### B. 实现细节

**韵律 Tokenizer 和内容-风格 Tokenizer**。本文处理和训练采样率为 \(24\mathrm{kHz}\) 的语音和歌声数据。对于 chromagram 特征提取，我们采用 Librosa 的实现，参数如下：FFT 点数设为 1920，hop 长度为 480，窗口大小为 1920，24 个 chroma 频带。对于 Whisper 隐藏特征 [27]，我们利用预训练 whisper-medium 模型的编码器输出。我们采用 Amphion [29], [30] 中的 VQ-VAE 实现，该实现服务于 MaskGCT [5] 和 Vevo [22]。我们唯一的修改是在编码器输入之前添加基于 CNN 的下采样层，并在解码器输出之后添加基于 CNN 的上采样层。提取的 chromagram 特征和 Whisper 特征均为 \(50\mathrm{Hz}\)。对于韵律 tokenizer，下（上）采样比为 8，产生 \(6.25\mathrm{Hz}\) 的 token 率，码本词汇量为 512。对于内容-风格 tokenizer，下（上）采样比为 4，产生 \(12.5\mathrm{Hz}\) 的 token 率，码本词汇量为 16,384。韵律 tokenizer 和内容-风格 tokenizer 分别包含 \(38\mathrm{M}\) 和 \(44\mathrm{M}\) 参数。

本研究中的所有模型使用 AdamW [94], [95] 作为优化器。对于两个 tokenizer，我们使用 1e-4 的峰值学习率，线性预热 10K 步，然后在剩余训练期间衰减。两个 tokenizer 均在 4 块 NVIDIA A100 GPU 上训练 300K 次更新（约 48 小时）。

**内容-风格建模**。在内容-风格建模阶段，我们使用 Qwen2.5-0.5B [96] 初始化 AR 模型，并扩展其原始词汇表以容纳我们提出的韵律 token 和内容-风格 token。AR 模型的总参数量为 \(509\mathrm{M}\)。对于基于 BPE 的文本 tokenizer，我们采用与 CosyVoice 2 相同的 tokenization 策略，即屏蔽一对多 token 以防止过长的发音长度并缓解数据稀疏导致的极端情况 [69]。在预训练期间，我们使用 5e-4 的峰值学习率，线性预热 32K 步，然后在剩余训练期间衰减。模型在 8 块 NVIDIA A100 GPU 上预训练 500K 次更新（约 168 小时）。

**声学建模**。在声学建模阶段，我们采用 Vevo [22] 的流匹配（FM）transformer 架构。该 transformer 由 16 层、16 个注意力头和 1024 的隐藏维度组成。FM 模型总参数量为 \(363\mathrm{M}\)。为提高训练效率，我们引入了 REPA 策略 [97]，并在训练过程中强制 transformer 第 5 层的隐藏输出与 W2v-BERT 2.0 特征 [5], [98] 对齐。我们使用 7.5e-5 的峰值学习率，线性预热 32K 步，然后在剩余训练期间衰减。FM 模型在 8 块 NVIDIA A100 GPU 上训练 700K 次更新（约 168 小时）。为开发用于语音和歌声的统一声码器，我们使用我们的训练数据（包含 101K 小时语音和 7K 小时歌声数据）微调 Vevo 的语音声码器 [22]。该声码器基于 Vocos 架构 [77]，包含 255M 参数，在 4 块 NVIDIA A100 GPU 上微调 572K 次更新（约 72 小时）。

**后训练**。在后训练期间，对于使用 20K M4Singer 样本的每次训练迭代，我们随机选择一种乐器并使用 pretty_midi\(^{10}\) 渲染相应音频。我们使用样本的原始文本并从这些渲染的器乐声音中提取韵律 token。我们采用 TRL\(^{11}\) 的训练框架。我们使用 5e-6 的学习率、批次大小为 3、rollout 数为 8，KL 系数为 0.1。模型在 8 块 NVIDIA A100 GPU 上后训练 9K 次更新（约 48 小时）。

## V. 结果与分析

### A. 统一建模对语音和歌声的益处

为研究语音和歌声生成是否可以通过统一建模互惠互利，我们考察了不同预训练数据分布对 Vevo2 的影响。具体来说，我们在零样本 TTS 任务上进行实验，并使用不同分布的参考提示评估性能。为进行比较，我们选择具有不同内容-风格 tokenizer 帧率的模型：MaskGCT [5]（50 Hz）、CosyVoice 2 [69]（25 Hz）和 F5-TTS [34]（没有内容-风格 tokenizer 的单阶段模型）。结果如表 I 所示，展示了以下发现：

（1）**语音和歌声生成从统一预训练中互惠互利**：比较不同预训练数据的 Vevo2 模型，我们观察到在表达性语音领域，联合使用语音和歌声数据进行预训练改善了所有指标（WER：\(15.52 \rightarrow 14.32\)，SIM：\(0.677 \rightarrow 0.681\)，N-CMOS：\(-0.84 \rightarrow -0.49\)，SS-CMOS：\(-0.06 \rightarrow -0.03\)）。在歌声领域，我们观察到仅使用歌声数据进行预训练相比仅使用语音数据产生更低的可懂度（WER：25.38 vs. 19.39），这可能是由于歌声语料库规模较小。此外，当结合语音和歌声数据进行预训练时，Vevo2 展现出更优的可懂度（WER：\(19.39 \rightarrow 15.78\)）和改进的自然度和相似度（N-CMOS：\(-1.02 \rightarrow -0.28\)，SS-CMOS：\(-0.48 \rightarrow -0.09\)）。

（2）**所提出的后训练的有效性**：所提出的后训练为预训练模型（Vevo2-base）带来了进一步的总体改进，包括增强的可懂度（WER）、说话人相似度（SIM 和 SS-CMOS）和自然度（N-CMOS）。这证明了后训练技术在可控语音和歌声生成中的有效性和巨大潜力。

（3）**Vevo2 与现有模型相比的竞争性能**：与基线相比，后训练的 Vevo2 在表达性语音领域在某些指标上匹配甚至超越它们，尽管其内容-风格 tokenizer 帧率较低。更重要的是，在歌声领域，Vevo2 在主观评估中大幅超越现有的零样本 TTS 模型（N-CMOS：差距大于 1.5；SS-CMOS：差距大于 0.9），这极大地受益于训练期间纳入歌声数据。这验证了 Vevo2 作为统一可控语音和歌声生成模型的有效性。

### D. 对时长的控制

如第 III-D 节所讨论，我们发现 Vevo2 通过利用韵律 token 作为输入，实现了生成输出的有效时长控制。这种能力源于一个基本特征：我们提出的韵律 tokenizer 和内容-风格 tokenizer 都以固定帧率运行（分别为 6.25 Hz 和 \(12.5\mathrm{Hz}\)）。在训练期间，这导致内容-风格 token 和韵律 token 的序列长度之间存在一致的线性关系，具体保持 2:1 的比例。AR 模型很容易学习这种简单的长度模式。因此，在推理期间，我们可以通过将线性缩放变换应用于韵律源的 chromagram 特征——利用 chromagram 特征对此类变换的固有鲁棒性——从而调节韵律 token 的长度，来控制输出时长。

在我们的实验中，我们研究了 Vevo2 在三个任务中的时长控制效果：语音编辑（SE）、歌唱歌词编辑（SLE）和风格转换 SVC。我们采用指标时长差异（DDUR，\(\downarrow\)）[22], [101]，它测量实际生成时长 \((\hat{d})\) 与目标时长 \((d)\) 之间的平均绝对差异（秒）。此外，我们引入时长一致性（DC，\(\uparrow\)）来评估时长控制的相对准确性：

\[\mathbf{DDUR} = \mathrm{abs}(\hat{d} -d),\quad \mathbf{DC} = \frac{\mathrm{abs}(\hat{d} -d)}{d}. \quad (7)\]

表 V：Vevo2 时长控制的效果。

| :--- | :--- | :--- |
| SE | 0.22s | 97.1% |
| SLE | 0.20s | 98.4% |
| SVC | 0.12s | 98.4% |

\* SE：语音编辑。SLE：歌唱歌词编辑。

对于编辑任务，遵循 F5-TTS [34]，我们根据编辑文本和原始文本长度之间的线性关系计算目标时长。对于风格转换 SVC，我们将目标时长约束为与源波形时长匹配。如表 V 所示，Vevo2 在所有三个任务中实现了超过 \(97\%\) 的时长一致性，尽管其具有自回归性质，仍展现出良好的时长可控性。

### F. 多目标后训练的有效性

为探索可懂度对齐和韵律相似度对齐的各自效果，我们对 Vevo2 的后训练过程进行了消融研究。具体来说，基于预训练模型（即 Vevo2-base），我们引入了一个仅使用可懂度奖励进行优化的后训练模型，记为 Base w/ Intelli。我们使用两个具有挑战性的任务进行评估：哼唱到歌唱和器乐到歌唱，这也展示了 Vevo2 在韵律控制方面的独特能力。对于器乐到歌唱任务，我们设计了两个主观指标（详见补充材料）：给定目标文本、目标旋律（即器乐声音）和生成的声音，受试者进行二元分类以确定声音是否准确演唱了文本（文本准确性）和旋律（旋律准确性）。

哼唱到歌唱和器乐到歌唱任务的评估集通过以下过程构建。对于旋律源，我们选择了哼唱样本 [88] 和器乐声音，包括长笛 [89] 和小提琴 [90] 录音。对于每个旋律样本，我们利用其 MIDI 标注的音符数使用 DeepSeek-v3 生成适当的歌词。以下提示用于 DeepSeek-v3：“I will provide the number of notes in a melody. Please write suitable lyrics for it. Note: (1) The number of words in the lyrics should roughly match the number of notes; (2) Please only return the result, without any further explanation.” 在获得旋律和歌词后，我们为每个样本从 SingStyle111 [20] 中随机分配一个目标歌手，从而创建形式为（旋律、歌词、歌手）的评估三元组。评估集包含 1,000 个样本，英语（500）和中文（500）歌词均匀分布。

图5所示的结果揭示了几个关键发现。当仅使用可懂度奖励时，模型在可懂度（WER 和文本准确性）方面表现出显著改进。然而，这种单目标优化可能损害其他目标，如 Base w/ Intelli 的旋律准确性甚至低于预训练模型（从 \(65.0\%\) 降至 \(50.0\%\)）所证明的。有趣的是，当联合使用两个奖励时，我们观察到旋律遵循和文本遵循能力均得到增强（例如，文本准确性从 \(75.0\%\) 提高到 \(90.0\%\)）。我们假设这种改进源于增强的韵律建模，进而有利于发音并因此增强可懂度。这进一步验证了我们提出的多目标后训练的优势。

## VI. 结论

本文介绍了 Vevo2，一个通过统一韵律学习桥接可控语音和歌声生成的框架。我们的方法利用两个提出的 tokenizer——一个从多样化音频源捕获韵律和旋律的无需乐谱的韵律 tokenizer，以及一个低帧率、音色解耦的内容-风格 tokenizer——以及统一的预训练策略和多目标后训练阶段。Vevo2 展示了有效性和多方面可控性，在语音和歌声的广泛合成、转换和编辑任务中实现了强大的泛化能力，并独特地实现了新颖应用，如哼唱到歌唱和器乐到歌唱。这些发现验证了统一建模对语音和歌声的互惠互利，突出了未来研究中进一步统一多样化音频领域和推进多方面可控性的有前景的方向。
